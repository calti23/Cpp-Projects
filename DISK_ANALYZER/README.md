# Disk Analyzer

## Overview
Disk Analyzer is a C++ application designed to analyze disk usage and storage information. It provides insights into how disk space is being utilized across your system.

## Features
- Analyze disk usage by directory
- Display disk space statistics
- Identify large files and folders
- Generate detailed reports on storage consumption

## Requirements
- C++11 or later
- Standard C++ libraries

## Compilation
To compile the Disk Analyzer project:

```bash
g++ -std=c++11 -o disk_analyzer main.cpp
```

## Usage
Run the compiled executable:

```bash
./disk_analyzer [options]
```

## Output
The application provides detailed information about:
- Total disk space
- Used space
- Available space
- Directory-wise breakdown

## Notes
- Run with appropriate permissions for full system access
- Results may vary depending on file system permissions
